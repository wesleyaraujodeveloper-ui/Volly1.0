Volly

Conector do Holyrics

O código gerado dentro do aplicativo Volly no celular do líder.

Por padrão o Holyrics usa a porta 8091.

Onde encontro o Token do Holyrics?
  1. Abra o programa Holyrics neste computador.
  2. Vá em Arquivo > Configurações.
  3. No menu esquerdo, clique em API Server. (Aproveite para confirmar a porta).
  4. Clique em Gerenciar Permissões e adicione um novo Token (dê o nome de Volly).
  5. Marque todas as caixinhas de permissão para esse token.
  6. Clique com o botão direito no token recém criado e escolha Copiar Token.
⚙️ Instalação do Script (Passo Único)

Como o Holyrics bloqueia a injeção automática de arquivos, você precisa colar o código abaixo diretamente no programa.

  1. No Holyrics, vá no menu superior em Arquivo > Configurações > aba API Server.
  2. Na parte inferior, clique no botão JavaScript.
  3. Se houver algum código lá, APAGUE tudo.
  4. Clique no botão 📋 Copiar Código abaixo e cole na tela limpa do Holyrics.
  5. Clique em Ok / Salvar.
